## 2. Adopt as additions (ranked)

1. **BOS/CHoCH (`bos_choch`)** — only true structure-trend signal in the set. Required to stop trading every FVG/OB in isolation. Emits trend-continuation (BOS) vs reversal-warning (CHoCH) with `Level/BrokenIndex`.
2. **Liquidity pools (`liquidity`)** — equal-high/low clustering is the "where stops sit" map; existing sweeps are the "what just happened" trigger. Pool + sweep confluence (pool level within 0.25 ATR of a sweep) is the highest-value new feature.
3. **FVG mitigation tracking (`Top/Bottom/MitigatedIndex` + `join_consecutive`)** — current `fvg_size` is a point event; reference adds a *zone lifecycle* (open → mitigated at index j → recyclable). Needed for "unmitigated FVG" filtering and older-to-newer zone priority.
4. **Configurable swing engine** — parameterize `find_swing_points` fractal radius (keep 2 as default) + add reference-style `swing_length` rolling engine behind a flag, BOTH with confirmation lag (§4). Unblocks (1) and (2) which consume `swing_highs_lows`.
5. **OB volume strength (`Percentage`) + `close_mitigation` flag** — `OBVolume = vol[i]+vol[i-1]+vol[i-2]`, `Percentage = min(hi,lo)/max(hi,lo)*100`; gate entries on `Percentage >= 50` (pre-register threshold). `close_mitigation=True` variant for daily bars (wick noise) vs `False` for intraday.
6. **MTF confirmation helper (§3)** — resample → compute → forward-fill → shift. Applies to BOS/pools/FVG, not a signal itself.

Explicitly NOT adopted: `sessions` (wall-clock overfit surface), `retracements` (no entry rule), verbatim `previous_high_low` (rewritten as §3 helper with explicit shift), second FVG/OB detectors.

## 3. Multi-timeframe confirmation approach

Rules (fail-closed, satisfies `leakage_guard.py`):
1. Compute HTF features on **resampled closes only** (`df.resample(htf).agg(open first/high max/low min/close last/volume sum)`), never on upsampled LTF rows.
2. Map HTF → LTF with `reindex(LTF.index, method='ffill').shift(1)` — the shift guarantees the LTF bar at `t` only sees HTF periods **closed before `t`**. No `.shift(0)`, no `bfill`.
3. Confirmation = AND, not replacement: `signal_LTF AND (BOS_HTF direction agrees OR price above HTF pool level)`. HTF never creates entries alone.
4. Suggested pairs: LTF 1H ← HTF 4H for BOS direction; LTF 15m ← HTF 1H for pool proximity. Daily strategies: LTF 1D ← HTF 1W `previous_high/low` breakout filter.
5. Cost: HTF resample is O(n); cache per (symbol, htf) in the backtest data loader, not per-signal call.

```python
def htf_confirm(ltf: pd.DataFrame, htf_rule: pd.Series) -> pd.Series:
    # htf_rule indexed by HTF period closes; ffill then 1-bar shift = no lookahead
    return htf_rule.reindex(ltf.index, method="ffill").shift(1)
# usage: long_ok = ltf_bos_bull & (htf_confirm(ltf, htf_bos_dir) > 0)
```

## 4. No-lookahead discipline for pivot detection (the critical section)

Reference lib is **lookahead-unsafe as written** — every function peeks:

| Reference lookahead | Why it leaks | Discipline (exact) |
|---|---|---|
| `fvg`: `shift(-1)` (needs next candle's low/high) | signal at `i` knows candle `i+1` | Emit signal at `i+1` (confirmation close) OR restrict to past-only form `high.shift(2) < low` already used in `smc.py:38` (signal at `i`, no future). Proposed `identify_fvgs_ex` keeps past-only detection, adds Top/Bottom, and computes `MitigatedIndex` by forward scan **stored as metadata, never as signal**: tradeable flag = `fvg_open = fvg & (mitigated_index.isna() \| mitigated_index > current_bar)` evaluated row-causally |
| `swing_highs_lows`: centered rolling `shift(-swing_length//2)` + edge anchoring (`swing[0]`, `swing[-1]` invented) | pivot at `i` confirmed by `i+swing_length/2` future bars | **Confirmation lag**: published pivot index = detection index, tradeable index = detection + `confirm` bars (`confirm = swing_length//2` for rolling engine, `2` for 5-bar fractal). Implement as `pivot_confirmed = pivot.shift(confirm)`; drop edge-anchored first/last rows (return NaN, never synthesize). Tests assert `tradeable <= detection - confirm` |
| `bos_choch`: signal parked at `last_positions[-2]` (a past swing) but `BrokenIndex` in future; unbroken rows **deleted** (`bos[k]=0`) | backtest sees only ex-post broken levels (survivorship) | Keep two columns: `bos_pending` (pattern complete, causal) and `bos_confirmed` (break observed at `BrokenIndex`, shifted). Live trading may act ONLY on `bos_confirmed.shift(1)`. Unbroken pruning is a **visualization-only** post-pass (`prune_unbroken=False` default; `True` only in notebooks) |
| `ob`: OB at `obIndex < close_index` defined by future close crossing a swing | retroactive write to past bar | Same rule as existing `smc.py:84` flaw: OB creation bar gets `ob_pending`; entry bar `i` is the signal bar. Feature for bar `t` = `max(ob_pending[t'] : t' + confirm_lag <= t)` (forward-filled, never back-filled). `OrderBlockDetector` already emits entries at `i` (correct); only its internal `ob_type[j]` array must not be read as a time-`j` signal |
| `liquidity`: `Swept` in future; grouping loop breaks at `swept` | pool known only after sweep | `pool_formed` (≥2 clustered swings, causal) vs `pool_swept` (sweep observed). Entry trigger = `pool_swept`, context = `pool_formed`. `Swept==0` (never swept) stays NaN, never 0-filled into a fake index |
| Mitigation scans (`mask = low[i+2:] <= top`) | future scan is fine IFF consumed causally | Allowed as *lifecycle metadata*; gate with `as_of` per `leakage_guard.detect_future_data`: `open_zone(t) = zone_start <= t < mitigated_index` with `mitigated_index > t` check at each `t` |

Existing-code audit (same lens):
- `smc.py:38-45` FVG — CLEAN (past-only). ATR `rolling(14).mean()` includes current bar = fine at close.
- `smc.py:80-94` OB — LEAKS if read at `j`: flag written to past bar `j` upon displacement at `i>j`. Must be consumed as "known at `i`" (forward-fill fix in Diff 1).
- `smc.py:106-107` sweeps — CLEAN (`.shift(1)`).
- `order_blocks.py:35-40` fractal — LEAKS 2 bars (uses `k+1,k+2`); tradeable = `swing.shift(2)`. Detection at `i-2` needing `low[i]` (lines 63-78) likewise = 2-bar lag, already consistent with entry at `i` — document, don't shorten.
- Column-convention trap: `smc.py` = lowercase (`high/low/close`), `order_blocks.py:200-203` = Capitalized (`High/Low/Close`). Any shared swing/BOS module MUST normalize once (`_norm(df)` in Diff 1) or half the features silently NaN.

```python
"""HTF confirmation for SMC (past-only). See §3."""
import pandas as pd
def resample_htf(df, rule="4H"):  # lowercase-normalized in, HTF closes out
    d = df.rename(columns={c: c.lower() for c in df.columns})
    return d.resample(rule).agg({"open":"first","high":"max","low":"min","close":"last","volume":"sum"}).dropna()
def htf_confirm(ltf_index, htf_series):
    return htf_series.reindex(ltf_index, method="ffill").shift(1)
def pool_sweep_confluence(pool_level, sweep_bar, atr, tol=0.25):
    return (pool_level - sweep_bar).abs() <= tol * atr
```

```python
def _bars(n=400, seed=7):
    rng = np.random.RandomState(seed)
    idx = pd.date_range("2020-01-01", periods=n, freq="h")
    close = pd.Series(100 + np.cumsum(rng.randn(n)*0.4), index=idx)

def test_fvg_past_only_no_shift_minus1():
```
